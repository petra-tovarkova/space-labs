# AI Collision Avoidance Prototype

Predicts potential collisions of a CubeSat with objects in LEO and provides recommendations for autonomous avoidance. Uses a simple neural network.

## Features
- Model training on synthetic object trajectory data
- Real-time collision prediction
- Integration with autonomous CubeSat control algorithms
