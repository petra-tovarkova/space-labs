# Magnetic Signature Detector

Analyzes CubeSat magnetometer data to detect nearby objects based on changes in the magnetic field.

## Features
- Loads time-series data from the magnetometer
- Detects sudden changes above a defined threshold
- Graphically highlights potential objects
