# Magnetorquer Attitude Control Simulator

Simulates CubeSat attitude stabilization using magnetorquers. Employs a PID controller to maintain the desired satellite orientation.

## Features
- CubeSat orbit simulation
- PID control of magnetorquers
- Graphical visualization of satellite orientation over time
