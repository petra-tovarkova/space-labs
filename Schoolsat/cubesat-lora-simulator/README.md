# LoRa Communication Simulator

Simulates LoRa communication for a CubeSat in Low Earth Orbit (LEO). The program models received signal strength, Doppler shift, and antenna orientation effects throughout the satellite’s orbit.

## Features
- Free Space Path Loss (FSPL) calculation
- Doppler shift simulation
- Antenna orientation impact on received power
- Graphical visualization of received power and Doppler shift
- CSV export for further analysis
